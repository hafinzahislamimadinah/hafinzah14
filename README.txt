HAFINZAH FOTOCOPY — WEBSITE

Cara menjalankan:
1. Extract ZIP.
2. Buka folder HafinzahFotocopy_Complete di Visual Studio Code.
3. Buka index.html dengan Live Server.
4. Edit alamat, nomor WhatsApp, email, jam buka, dan harga contoh di index.html.

File:
- index.html = struktur website
- style.css = desain/responsive
- script.js = menu mobile, animasi, FAQ, navigasi aktif

Catatan:
Nomor WhatsApp pada tombol masih contoh 6280000000000.
Harga dan alamat juga masih contoh dan sebaiknya diganti dengan data toko sebenarnya.
